# 康伴（微信小程序版）

这是一个医药健康管理的小程序 Demo，包含：

- 用药提醒管理（添加/删除）
- 症状记录（强度、备注、时间）
- 今日健康概览（提醒数、症状数、平均强度）
- 本地存储持久化（`wx.setStorageSync`）

## 目录结构

- `miniprogram/app.json`：全局配置
- `miniprogram/pages/index/*`：首页与主要功能

## 使用方式

1. 打开微信开发者工具
2. 选择 `miniprogram` 目录导入项目
3. 使用测试号（`touristappid`）本地运行
